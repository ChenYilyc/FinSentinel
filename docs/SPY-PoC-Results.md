# SPY 五交易日方向预测 PoC 实验记录

2026-11-18 · 历史回放 · 模型版本 `spy-lr-24e970b67100`

## 如何演示

打开项目根目录的 `FinSentinel-SPY-PoC.html` 即可离线查看预测卡、分窗口指标、校准图和最近一条已结算预测，页面可导出 756 条逐日结果。在线开发入口为 `http://127.0.0.1:8000/#forecast`。二者使用同一份 React 组件与冻结结果。

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

项目接口为 `GET /api/forecast` 和 `GET /api/forecast/history.csv`。模型仅在离线命令中训练。原有持仓面板继续使用其独立的模拟价格。

## 数据与方法

使用公开教育项目保存的 Yahoo Finance SPY 历史复权收盘价（Adj Close），固定取 2016-07-25 至 2026-07-23 的 2,513 个交易日。源 CSV 的 Git blob 为 `52c647e871bd687c664db8ca8db0c23a75e6b8b2`。本地 `examples/spy_adjusted_close.csv` 只提取日期和复权收盘价，按 LF 换行计算的 SHA-256 为 `3dbffd8e15a2beae9aedde1e09ecb70510074c03bf8b40f74e042dbaadcbf2eb`。使用范围为本地教育性研究，公开发布原始报价前需另行核对授权。[数据说明](https://github.com/Setooooo/etf-insight/blob/master/data/SOURCE.md)

核验交易日排序、重复、缺失、价格及校验值。日历按本冻结期的全日休市规则计算，提前收市计为交易日，另含 2018-12-05 和 2025-01-09 两个特殊休市日。输入与预期交易日逐日相符。该检查专用于本快照。[交易所日历](https://www.nyse.com/trade/hours-calendars)

标签为第五个后续交易日复权收盘价是否严格高于当天。六个特征包括 1、5、20 日收益，5、20 日日收益样本标准差和相对 20 日均线偏离。前 20 行用于特征预热，最后 5 行没有到期标签，共 2,488 个已标注样本。每次训练独立拟合 StandardScaler，再拟合 L2 逻辑回归，C=1。基线使用同次训练集的上涨频率。

预先固定最后三个连续的 252 日窗口。每窗冻结模型，训练只保留标签在窗口首日之前到期的样本。展示的快照末日概率单独在收盘后拟合，允许使用当日已结算标签。权重、标准化参数、特征顺序、软件版本及逐日结果保存在 `forecast/result.json`。这是一份事后取得的价格快照，历史结果未使用逐日供应商版本存档，亦未进行实时前瞻跟踪。

## 样本外结果

| 测试日期 | 天数 | 实际上涨率 | 模型准确率 | 基线准确率 | 模型 Brier | 基线 Brier |
|---|---:|---:|---:|---:|---:|---:|
| 2023-07-12 至 2024-07-11 | 252 | 66.27% | 66.27% | 66.27% | 0.226746 | 0.225389 |
| 2024-07-12 至 2025-07-15 | 252 | 59.13% | 59.52% | 59.13% | 0.242190 | 0.242881 |
| 2025-07-16 至 2026-07-16 | 252 | 60.71% | 60.71% | 60.71% | 0.242144 | 0.238719 |
| **汇总** | **756** | **62.04%** | **62.17%** | **62.04%** | **0.237027** | **0.235663** |

模型比基线多判对一个方向。概率误差在三个窗口中有一个低于基线，总体 ΔBrier 为 +0.001364。本次实验未观察到稳定的概率预测增益。相邻五日持有期有重叠，756 条记录不等于 756 次相互独立的实验。校准图按十个等宽概率区间汇总，并在图中展示有样本的点。

**已结算回放**　2026-07-16 模型估计上涨概率 63.23%，基线 62.12%。至 07-23 实际收益为 −1.67%，真实类别为下跌。

**快照末日**　2026-07-23 模型估计上涨概率 63.56%，基线 62.06%，对应到期日 07-30。在冻结文件内没有 07-30 的收盘价，结果仅标为“快照中待结算”。
