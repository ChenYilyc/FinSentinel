# FinSentinel 项目目标与五日预测 PoC 验收说明

**评审稿 v0.1 · 2026 年 11 月 18 日 · 待项目负责人确认**

## 一　项目描述

> FinSentinel 是一个面向投资者与客户经理的金融分析项目，目标是将市场公告、日频行情与客户持仓关联起来，让用户能够追溯一项判断的原文、复算持仓风险，并在订阅条件触发时收到提醒。项目已实现基于模拟行情的持仓风险面板。近期计划优先开发 SPY 五个交易日方向预测原型，用真实历史行情检验模型相对简单基线的表现。公告检索、Agent 工具调用与持续预警属于后续扩展。

本段可直接用于当前项目介绍。对外展示时，待回测完成后再填入真实的数据期间、样本量和模型表现。

## 二　整体目标及业务意义

完整展示版计划覆盖 10–20 个美股标的，以美元日频数据分析持仓，以一个宽基 ETF 表示市场方向。以下指标用于检验系统能否回答用户的问题。表中未来目标均待实测。

| 用户希望回答的问题 | 目标功能与业务意义 | 衡量方式与当前状态 |
|---|---|---|
| 我的风险集中在哪里？ | 按资产与行业展示市值、权重及假设跌幅下的损失，让客户经理可以现场复算 | **已有模拟原型。** 参考组合 100,000 美元，半导体占 42%；假设该行业下跌 8%、其他价格固定，组合损失应为 3,360 美元。阶段一已通过 7 项计算测试，本机浏览器与容器操作仍待验收 |
| 这份公告与哪些持仓有关？ | Agent 检索原文、匹配持仓、调用风险工具，把公司直接敞口和行业关联分开说明 | **未来目标。** 抽查 20 个字段至少 18 个正确；已发布的数值引用全部能定位并支持结论。10 个检索问题中至少 8 个能在前五个结果找到标注证据 |
| 近期方向判断比历史经验多提供了多少信息？ | 输出指定 ETF 的五日上涨概率，同时展示历史上涨频率，让用户看到判断依据和历史误差 | **近期 PoC。** 在相同样本上比较模型与基线，至少报告三个测试窗口，保留逐日预测及到期结果 |
| 哪些变化值得再次提醒？ | 在数据更新后按订阅条件触发提醒，减少同一事件被反复通知 | **未来目标。** 对同一用户、组合、规则与事件重复投递三次，只产生一条站内提醒；每条能追溯到触发条件和来源快照 |

**业务价值如何验证。** 上述指标可检验计算能否复算、证据能否找到、提醒是否重复。若将来要声称“节省了客户经理的分析时间”，用同一批公告与持仓做人工流程和工具辅助流程的对照，记录任务完成时间中位数及正确率，再报告实测差异。

## 三　近期 PoC 的功能范围

**预测问题。** 当 SPY 在交易日 t 的收盘行情已发布，估计其复权收盘价从当日到第五个后续交易日累计收益大于零的概率。实际标签为 `y = 1[P(t+5) / P(t) - 1 > 0]`，收益为零归入 0。该概率描述 SPY；持仓模块的行业权重和压力情景另行展示。

| 项目 | 本次拟交付 |
|---|---|
| 数据 | 一个标的 SPY，一份允许用于本项目的日线数据。目标覆盖 8–10 年，保留交易日期、复权收盘价、来源、复权口径、截止日和数据版本 |
| 特征 | 六项价格特征：1、5、20 日累计收益率，5、20 日日收益率波动率，以及收盘价相对 20 日均线的偏离度 |
| 方法 | 一个历史频率基线，加一个自训练逻辑回归模型。基线概率取各训练窗口已到期标签的上涨占比；两者按同一组测试日期评估 |
| 展示 | 一个只读预测接口、一张 React 预测卡、一份逐日样本外结果。卡片显示数据截至日、预测期限、模型概率、基线概率及模型版本 |
| 扩展接口 | 后续 Agent 可按标的、时点、期限查询同一预测结果。LightGBM 作为下一轮对照实验，文档分析、定时提醒与公网部署另排期 |

## 四　PoC 验收清单

| 编号 | 可勾选的通过条件 | 留存证据 |
|---|---|---|
| P1 数据 | [ ] 核对交易日顺序、重复与缺失，未解释的缺口不进入五日标签计算。记录真实覆盖期和有效样本量 | 数据摘要、文件校验值、清洗记录 |
| P2 标签 | [ ] 人工抽查 3 个日期，五日到期日和涨跌标签全部匹配。末尾 5 个尚未到期的起始日不进入有标签训练集 | 抽查表及自动化测试 |
| P3 时序 | [ ] 至少 3 个按时间排列、互不重叠的测试窗口。每个窗口中，训练标签到期日均早于测试起始日；标准化只在训练集拟合，最终测试集不参与选择模型参数 | 窗口起止日期、边界断言、训练配置 |
| P4 评估 | [ ] 每个窗口列出样本量、实际上涨率、基线和模型的方向准确率及 Brier 分数；提供汇总校准图和逐日预测 | 模型对照表、校准图、预测结果文件 |
| P5 演示 | [ ] 展示 1 条已到期的历史回放，能核对预测日期、预测概率、到期收益及真实标签；再展示 1 条基于数据末日、在该快照中待结算的预测，并标注数据截止日 | 接口响应、预测卡、对应两条记录 |
| P6 复现 | [ ] 在相同依赖、数据与配置下，用一条命令重跑；测试日期、标签、样本数一致，概率与指标保留六位小数后一致 | 运行命令、模型版本、两次结果对照 |

**怎样判断模型是否带来增量。** Brier 分数是预测概率与实际 0/1 标签之间的平均平方误差，越低越好。记录差值 Δ = 模型 Brier − 基线 Brier；负值表示模型在该批样本上的概率误差更低。方向准确率统一按概率 ≥ 0.5 判为上涨。汇总指标用所有测试日期的逐日结果计算，同时保留各窗口结果，防止单个时期掩盖其他时期。相邻预测的五日区间有重叠，解读样本量时应考虑这种相关性。

**签收口径。** P1–P6 全部通过即可签收工程 PoC。若模型在样本外没有超过基线，记录“本次实验未观察到增益”及对应指标。准确率、投资收益、节省时间均以实际证据填写。历史回放与当日真实生成的前瞻预测分别标记，后者满五个交易日后才能结算。
